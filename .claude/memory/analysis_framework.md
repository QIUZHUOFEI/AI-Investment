## 分析框架

分析全球市场/行业时，**不分国内国外章节**，统一按全球视角写。

### 中国企业的处理方式

| 情况 | 处理方式 |
|:-----|:---------|
| **中国企业能在全球排上号**（市占率可观或有全球竞争力）| 和前面的全球企业放一起**同等分析**，不单独分一节 |
| **中国企业完全上不了全球桌** | 只在文末**一笔带过**：提一下国内最头部是谁，离国际差距有多大，不用多写 |

### 举例

- **液冷**：英维克打入了 Google/NVIDIA 供应链，能上全球桌 → 和 Vertiv、Schneider 放一起分析
- **HBM**：长鑫存储 HBM 全球份额 ~4%，差距 2-3 年 → 文末一笔带过即可
