## 一、为什么刻蚀如此重要？

芯片制造三核心步骤：**光刻 → 刻蚀 → 沉积**。光刻画图案，刻蚀把图案刻进去。

刻蚀步骤数量随制程提升暴增：

| 制程节点 | 刻蚀步骤数 | 中微参与度 |
|:---------|:----------|:----------|
| 28nm | ~30 次 | 部分 |
| 7nm | ~50 次 | ✅ CCP 刻蚀 |
| 5nm | ~70 次 | ✅ **已切入供应链** |
| 3nm | **~100+ 次** | 验证中 |

> 🔑 **核心逻辑**：AI 芯片需要越先进的制程 → 刻蚀步骤越多 → 中微的产品需求越大。
