## 三、哪些领域正在"爆发期" vs "早期"

| 阶段 | 领域 | 特点 |
|:-----|:-----|:------|
| **🔥 爆发期（业绩已在兑现）** | 光模块（800G/1.6T）| 增速 100%+，毛利率持续提升，订单排到 2028 |
| **🔥 爆发期** | AI 定制芯片（XPU）| Broadcom AI 收入 +106% 且还在加速 |
| **🌱 爬坡期（即将放量）** | 液冷散热 | 渗透率正在突破 50%，但业绩还在爬坡 |
| **🌱 爬坡期** | 交换机（Scale-up） | 超节点架构推动交换机用量暴增，2026 是元年 |
| **🌱 爬坡期** | HBM 存储 | 跟着 GPU 走，海力士/三星已经在大量出货 |
| **🪴 早期（还在布局）** | Token 工厂 / 算力租赁 | 模式刚跑通，但公司基本面参差不齐 |
| **🪴 早期** | CPO（共封装光学）| 2027 年才可能大规模商用，但专利布局已经开始 |
