# 🌡️ 液冷 / 散热

> AI 数据中心的"空调"——GPU 越来越热，风冷顶不住了。

---

## 产业链位置

液冷属于 **第三层（基础设施配套）**，解决 AI 数据中心最头疼的问题：散热。

## 为什么液冷是必然趋势？

```
GPU 功耗进化：
A100（400W）→ H100（700W）→ B200（1000W+）→ Rubin（？）

风冷极限：~800W/芯片
液冷：可应对 1500W+ 的芯片功耗
```

英伟达 GTC 2026 发布的 Rubin 平台已经明确采用液冷方案。
