## 一、为什么 AI 需要欣兴？

每一颗 AI 芯片（H100/B200/MI400）都要封装在 **ABF 载板**上——这是芯片和 PCB 之间的「桥梁」：

```
B200 GPU → CoWoS 封装 → ABF 载板 → PCB 主板
                            ↑
                     欣兴电子是 ABF 载板全球第一
```

| ABF 载板厂商 | 全球份额 | 主要客户 |
|:-------------|:---------|:---------|
| **欣兴电子 🥇** | **~25%** | NVIDIA、AMD、Intel |
| Ibiden 🥈 | ~20% | Intel、AMD |
| AT&S 🥉 | ~15% | NVIDIA、AMD |
| 景硕/南亚 | ~15% | 台系芯片厂 |

## 三、ABF 载板：AI 芯片的「隐形瓶颈」

ABF（Ajinomoto Build-up Film）载板是 AI 芯片封装的关键材料，2023-2026 年持续供不应求：

| 年份 | ABF 载板供需 | 欣兴产能扩张 |
|:-----|:------------|:------------|
| **2023** | 供不应求（缺口 ~10%）| 产能满载 |
| **2024** | 仍然吃紧 | 新厂爬坡 |
| **2025** | 紧平衡 | 台湾新产能开出 |
