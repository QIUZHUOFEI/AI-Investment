# 🖥️ 服务器 / 整机

> AI 算力的"总装厂"——把 GPU、CPU、内存、散热装成一台能用的机器。

---

## 产业链位置

服务器位于 **第三层（基础设施配套）**，是算力芯片→算力服务的"最后一公里"。

```
上游（零件）     →     整机集成      →     下游（客户）
GPU（英伟达）           浪潮信息            云厂商
CPU（Intel）            工业富联            互联网大厂
存储（SK海力士）        中科曙光            运营商
PCB（沪电股份）         华勤技术           政府/企业
液冷（英维克）
```

## 核心公司

| 公司 | 定位 | 核心逻辑 |

## 关键趋势

- **2026 是国产超节点元年**：浪潮、中科曙光、华勤都在推国产 AI 服务器
- **利润在向中游整机流动**：工业富联 Q1 利润翻倍，整机集成环节开始释放利润
- **字节 2000 亿资本开支**：2026 年字节 AI 资本开支上调至 2000 亿，浪潮信息是最大受益者
