# 🏭 算力基础设施

> AI 算力的"房地产"——数据中心 + 算力租赁，是 AI 时代的新基建。

---

## 产业链位置

算力基础设施位于 **第三层（基础设施配套）**，是把算力芯片变成可服务的"最后一环"。

## 两个方向

### 方向一：IDC（数据中心）—— 出租机房和机柜

| 公司 | 定位 | 核心逻辑 |
|:-----|:------|:---------|
| **润泽科技** | 国内 IDC 龙头 | 绑定字节等大客户，机柜量国内第一 |
| 万国数据 | 国内 IDC 龙头 | 服务云厂商为主，近年来增速放缓 |
| 奥飞数据 | IDC + 算力平台 | 受益于 AI 算力需求增长 |

### 方向二：算力租赁 / Token 工厂 —— 出租算力本身

| 公司 | 定位 | 核心逻辑 |
|:-----|:------|:---------|
| **润建股份** | **Token 工厂先行者** | 自建万卡集群，按 Token 量计费，模式创新 |
| 宏景科技 | 全球化 Token 工厂 | 算力服务收入占 89%，面向全球客户 |

## 为什么 Token 工厂是新的东西？

传统模式：按月租裸金属服务器，不管用不用都付钱
Token 模式：按实际消耗的 Token 量计费，像交水电费一样

这本质上是 **"算力从资产→公共事业"** 的转变，跟国家推的"算力网"政策方向一致。
