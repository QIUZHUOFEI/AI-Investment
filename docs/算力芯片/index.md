# 🔵 算力芯片

> AI 的"大脑"——算力芯片是整个 AI 产业链的起点。

---

## 产业链位置

算力芯片位于 **最底层**，是所有 AI 应用的物理基础。没有芯片就没有 AI。

```
上游（设计/代工）    →    算力芯片     →    下游（硬件/应用）
台积电 / ASML              英伟达             光模块 / 服务器
                           AMD              液冷 / 数据中心
                           Broadcom          
                           寒武纪
```

## 分为三个方向

| 方向 | 代表公司 | 特点 |
|:-----|:---------|:-----|
| **通用 GPU** | 英伟达（~80% 市场）、AMD | 通用性最强，适用于训练+推理，生态最成熟 |
| **定制 AI 芯片（XPU/ASIC）** | **Broadcom**（已覆盖）、Marvell | 大客户自研架构，Broadcom 代工制造，特定场景效率更高 |
| **国产 AI 芯片** | 寒武纪、海光信息 | 性能有差距，但靠超节点集群化弥补，政策驱动 |

## 关键趋势

- **英伟达 Rubin 平台**：2026 下半年量产， Blackwell 的下一代
- **超节点（Scale-up）**：国产芯片通过更密集的互联弥补单卡差距，利好交换芯片和光模块
- **定制芯片崛起**：Google/Meta/OpenAI 都在搞自己的 XPU，Broadcom 是最大受益者
